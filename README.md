<h1 align="center">🪙 Crypto Portfolio Management System</h1>
<p align="center">A data-driven web app to track and analyze your cryptocurrency investments</p>
The Crypto Portfolio Management System is a data-driven web application designed to help users track, analyze, and manage their cryptocurrency investments in real time. It provides users with insights into portfolio performance, price fluctuations, and market trends through an intuitive interface.

⚙️ Features

💰 Portfolio Tracking: Add, update, or remove cryptocurrencies from your portfolio.

📊 Live Price Monitoring: Fetches real-time crypto prices from public APIs.

📈 Data Visualization: Displays charts showing portfolio distribution and performance over time.

🧮 Profit/Loss Calculation: Automatically computes gains or losses for each holding.

🔐 User-Friendly Interface: Simple and interactive design for smooth navigation.

🧠 Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: Python (Flask / Django)

Database: SQLite / MySQL

APIs: CoinGecko or Binance API for live market data

Libraries: Pandas, Matplotlib, Requests

🚀 How It Works

User adds cryptocurrencies and their purchase details.

The system fetches current market prices via an external API.

It calculates total investment, current value, and percentage returns.

Visual dashboards display portfolio insights dynamically.

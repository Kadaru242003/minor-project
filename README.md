<h1 align="center">🪙 Crypto Portfolio Management System</h1>
<p align="center">
  The <b>Crypto Portfolio Management System</b> is a data-driven web application designed to help users track, analyze, and manage their cryptocurrency investments in real time.<br>
  It provides users with insights into portfolio performance, price fluctuations, and market trends through an intuitive interface.
</p>

## ⚙️ Features

- 💰 **Portfolio Tracking:** Add, update, or remove cryptocurrencies from your portfolio.  
- 📊 **Live Price Monitoring:** Fetches real-time crypto prices from public APIs.  
- 📈 **Data Visualization:** Displays charts showing portfolio distribution and performance over time.  
- 🧮 **Profit/Loss Calculation:** Automatically computes gains or losses for each holding.  
- 🔐 **User-Friendly Interface:** Simple and interactive design for smooth navigation.  

---

## 🧠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Flask / Django)  
- **Database:** SQLite / MySQL  
- **APIs:** CoinGecko or Binance API for live market data  
- **Libraries:** Pandas, Matplotlib, Requests  

---

## 🚀 How It Works

1. Users add cryptocurrencies and purchase details.  
2. The system fetches current market prices via an external API.  
3. It calculates total investment, current value, and percentage returns.  
4. Visual dashboards show portfolio insights and analytics.
